# Machine Learning Experiments 🚀

This repository contains a collection of machine learning experiments built using Python and Scikit-learn.  
Each project focuses on understanding different ML concepts such as classification, clustering, dimensionality reduction, and neural networks.

---

## 📌 Projects Included

### 1. Iris Classification (Logistic Regression)
- Basic classification using Logistic Regression
- Evaluation using accuracy and confusion matrix

---

### 2. Iris PCA + Preprocessing Comparison
- Introduced missing values and handled them
- Applied StandardScaler and MinMaxScaler
- Dimensionality reduction using PCA
- Compared model performance

---

### 3. Model Comparison (KNN, SVM, Decision Tree)
- Compared multiple classification algorithms
- Feature scaling applied where necessary
- Evaluated models using accuracy score

---

### 4. Clustering vs Classification
- Applied KMeans clustering (unsupervised learning)
- Compared with supervised models (Logistic Regression, Decision Tree)
- Analyzed differences in learning approaches

---

### 5. Neural Network (MLPClassifier + GridSearchCV)
- Built a neural network using MLPClassifier
- Applied feature scaling
- Tuned hyperparameters using GridSearchCV
- Compared base model vs optimized model

---

## 🧠 Skills Demonstrated

- Data preprocessing
- Feature scaling (StandardScaler, MinMaxScaler)
- Dimensionality reduction (PCA)
- Supervised learning (Classification)
- Unsupervised learning (Clustering)
- Neural networks (MLPClassifier)
- Hyperparameter tuning (GridSearchCV)
- Model evaluation
